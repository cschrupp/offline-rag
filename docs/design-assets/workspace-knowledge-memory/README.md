## Supplied concept assets

These standalone assets are reconstructed from the original assistant-authored diagram and mockup markup in the design conversation, not extracted screenshot files or original rendered bytes. The original labels, geometry and conceptual intent of the two SVGs are retained; theme-dependent colors are resolved to a neutral light theme. The conversational recovery card is recreated as a standalone HTML mockup, including its expandable explanation. It is not production code.

- `knowledge-memory-architecture.svg`: original four-category architecture. Hindsight-inspired lifecycle, A-MEM-inspired organization; Seneca-specific categories and provenance rules.
- `workspace-knowledge-tab.svg`: original three-column workspace wireframe with Evidence/Knowledge tabs; the original app header is represented in the mockup wrapper below.
- `workspace-mockup.html`: complete workspace mockup presentation, with header and original wireframe.
- `conversational-recovery.html`: original example recovery response (illustrative, not a diagnosed incident).
