# CPU Stage 1 diagnostic materials

This directory preserves the exact Stage 1 authorization, temporary probe and runner source, source checksum list, and short execution records recovered from `/tmp`. The probe/runner are historical evidence, not an authorization to rerun or contact the review VM. `files.sha256` verifies the eight application source copies against their pinned code revision; those copies are not duplicated here because the PR branch retains them.

The credential-bearing SSH key used at execution time is deliberately excluded.

The historical runner has its review-host address redacted; it is archival evidence and is not authorized to run.
